This is a simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. The game allows two players to play against each other on the same device, with a clean and responsive interface. It includes automatic win detection, draw detection, and the ability to restart the game.

🚀 Features

Two-player gameplay

Win and draw detection

Game reset/restart option

Simple, clean, and responsive UI

Smooth JavaScript interactions

🛠️ Tech Stack

HTML

CSS

JavaScript

📦 About

This project was created to practice DOM manipulation, event handling, and game logic using vanilla JavaScript. It also helped in improving UI design skills with basic HTML and CSS.
